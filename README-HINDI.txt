This version uses Cloudflare Pages + Pages Functions + Supabase.
Do not use Cloudflare's Direct Upload workflow for this package.

After connecting this folder to a GitHub repository and creating the Pages project:
Cloudflare > your Pages project > Settings > Variables and Secrets > Add:
SUPABASE_URL = your Supabase Project URL
SUPABASE_PUBLISHABLE_KEY = your Supabase Publishable key

Do NOT use or upload a Supabase service_role/secret key.
